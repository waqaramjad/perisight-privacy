# PeriSight AI privacy policy

The privacy policy for the PeriSight AI iPhone app.

Read it at **https://waqaramjad.github.io/perisight-privacy/**

Questions and requests to delete feedback: open an issue in this repository. Issues
are public, so please don't put personal details in one. You can also use Settings →
Send feedback in the app.
